# Mobile Price Prediction

## Project Overview
This Machine Learning project predicts the price range of a mobile phone based on its features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Project Workflow
1. Load and explore the dataset.
2. Preprocess the data.
3. Train a Machine Learning model.
4. Predict the mobile phone price range.
